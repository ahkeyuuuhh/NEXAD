# Font Files — Rename and place these here

Download the fonts and rename the files exactly as shown below:

| Font          | Download name              | → Rename to             |
|---------------|----------------------------|--------------------------|
| Milker        | Milker.ttf (or similar)    | `Milker-Regular.ttf`     |
| Garet (light) | Garet-Book.ttf (or similar)| `Garet-Book.ttf`         |
| Garet (bold)  | Garet-Heavy.ttf (or similar)| `Garet-Heavy.ttf`       |

Place all 3 `.ttf` files in this folder.
