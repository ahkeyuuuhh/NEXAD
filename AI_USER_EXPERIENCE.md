## 🚨 IF SOMETHING DOESN'T WORK

**Alert doesn't appear:**
- Check you typed >30 characters in reason field
- Wait at least 1 second after typing
- Check console logs for errors

**AI chat doesn't open:**
- Check for JavaScript errors in console
- Verify modal permission (should open automatically)

**AI doesn't respond:**
- Check aiService.ts is included in build
- Check network connection for Supabase
- Look for error messages in chat

**Smart Brief not visible:**
- Check ai_smart_briefs table in Supabase
- Verify RLS policies are enabled
- Check console for generation errors
